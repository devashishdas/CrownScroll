# CrownScroll Privacy Policy

Effective date: 20 October 2026

CrownScroll is a browser extension intended to help users navigate long conversations on chatgpt.com and chat.openai.com.

**What the extension accesses:** CrownScroll examines limited page structure, including conversation message elements, scrolling containers, and scroll position, to determine which part of the page should move. The extension does not extract, persist, or transmit message text.

**What it stores:** CrownScroll stores user interface preferences (enabled status, theme, floating position, navigation mode, and wheel sensitivity) in Chrome's local extension storage on the user's device. These settings are removed when the extension is uninstalled or its local data is cleared.

**What it transmits:** This release does not make network requests, send data to any developer-operated server, use analytics, or sell personal data. It has no login system. It does not collect conversation text, credentials, or browsing history.

**Permissions:** `storage` saves preferences. `scripting` and `activeTab` allow the user to restore the floating toolbar on the active ChatGPT tab. The content script is restricted to ChatGPT webpages.

**User controls:** Disable the extension in its popup or remove it via Chrome's extensions page. Clear its local extension data by uninstalling the extension.

**Third-party services:** CrownScroll is independent software, not affiliated with OpenAI. It runs in the user's browser on ChatGPT pages; use of ChatGPT is subject to OpenAI's separate terms and privacy policies.

**Updates:** Material privacy changes must be reflected in this policy and the store listing before publishing an updated release.

**Contact:** The publisher must insert and verify a support contact address before hosting this policy or publishing. This file is a draft that matches the audited v1.3 release source and must be reviewed by the publisher.
