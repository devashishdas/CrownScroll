# Contributing

Bug reports, reproducible test cases, compatibility observations, and UI suggestions are welcome through GitHub Issues. Do not include private ChatGPT messages or secrets in reports.

Code contributions are **not being accepted yet** because a source-code license and contribution agreement have not been selected. Please open an issue to discuss a change before submitting a pull request.

For a bug report, include Chrome version, operating system, CrownScroll version, navigation style, relevant settings, steps to reproduce, and expected versus actual behavior.
