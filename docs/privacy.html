Privacy Policy

Effective 20 October 2026 · CrownScroll browser extension version 1.3.0

CrownScroll is an independent Chrome extension that adds floating navigation controls to ChatGPT conversations. It operates locally in the browser on chatgpt.com and chat.openai.com.

Information processed on your device

To locate the scrolling area and display navigation controls, CrownScroll examines local page structure and scroll state, including element dimensions and scrolling positions. It does not need to collect, copy or retain the text of your conversations.

Settings stored locally

CrownScroll stores interface preferences in Chrome's local extension storage: enabled status, theme, navigation style, toolbar location and thumbwheel sensitivity. This local data remains until you clear it or uninstall the extension.

Data collection and transmission

Version 1.3.0 does not contain a developer-operated backend, analytics, advertisements, an account system or payment integration. The packaged extension does not send page content or preferences to the developer. The developer does not receive your conversation text, credentials, browsing history or extension preferences through this version.

ChatGPT and your browser are separate services with their own data practices and privacy policies.

Browser permissions

  • storage saves local user preferences.
  • scripting restores packaged navigation scripts when needed.
  • activeTab supports toolbar recovery on the active ChatGPT tab.
  • Content scripts operate only on declared ChatGPT website addresses.

All executable extension JavaScript is packaged locally; no remote executable code is loaded.

Your controls

Disable CrownScroll in its popup or uninstall the extension through Chrome's extension management page (chrome://extensions). Uninstalling or clearing extension storage removes saved preferences.

Changes to this policy

If a future version changes data handling, this policy and applicable store disclosures will be updated before publication of the new version.

Contact

For support or privacy inquiries, use the Issues tab of the official CrownScroll GitHub repository, or the verified developer contact information provided by the Chrome Web Store listing. Do not post passwords or private chat messages to public issues.

Independence

CrownScroll is independent third-party software, not affiliated with or endorsed by OpenAI.
